# Datasets

| File(s) | Dataset | Source | Licence |
|---|---|---|---|
| `ai4i2020.csv` | AI4I 2020 Predictive Maintenance Dataset (10,000 milling records, 339 failures) | S. Matzka, UCI Machine Learning Repository, https://doi.org/10.24432/C5HS5C | CC BY 4.0 |
| `train_FD001.txt`, `test_FD001.txt`, `RUL_FD001.txt`, `train_FD003.txt`, `test_FD003.txt`, `RUL_FD003.txt` | NASA C-MAPSS Turbofan Engine Degradation Simulation Data Set | A. Saxena and K. Goebel, NASA Ames Prognostics Data Repository | US government work, public domain |

The files are unchanged copies of the original releases. Checksums are listed in `SHA256SUMS`.
To use another folder, set the environment variable `NFF_DATA` to its path.
